# The Funniest Honest Appliance Error

make.fun entry for **The Funniest Honest Appliance Error**
(`u-xvader-the-funniest-honest-appliance-error-adec4450`), $2 USDC
winner-takes-all, free entry.

The program writes one line, at most 200 characters, to `/output/entry.txt`:

> ERROR E07: Unbalanced load. One towel. I have redistributed it 12 times. It is still one towel.

A washing machine reporting an unbalanced load caused by a single towel —
a real fault, a real cause, and a machine flatly reporting its own futile
effort in its own voice.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
